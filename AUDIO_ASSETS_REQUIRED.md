# Требуемые аудиофайлы

> **Обновлено (release-audit-findings):** URL сэмплов теперь base-aware — `${import.meta.env.BASE_URL}audio/<key>.mp3`, а не абсолютный `/audio/<key>.mp3` (ломался при каталожном размещении с `base` не `/`). Пути ниже в таблице — иллюстративные имена файлов в `public/audio/`, не буквальный URL в рантайме.

**Статус на 2026-08-29:** все 20 из 20 файлов реестра лежат в `public/audio/` — записаны/сгенерированы, обработаны (нормализация громкости, обрезка тишины) и подключены через `playSample()`. Игра больше не полагается на синтезированный fallback ни для одного зарегистрированного ключа: `star_collect`, `gate_creak`, `gate_swing`, `button_click`, `crate_slide`, `wood_hit`, `metal_hit`, `dog_bark`, `chickens_scatter`, `tractor_start`, `boss_phase`, `victory_drive`, `grandpa_mumble_1/2/3`, `engine_idle`, `engine_low/high`, `tractor_idle/move`. Последними были добавлены `grandpa_mumble_1.mp3`…`grandpa_mumble_3.mp3` (реплики деда — P0) и `gate_swing.mp3` (P3), сгенерированные ElevenLabs sound-effects и обработанные ffmpeg (обрезка тишины, приведение к моно 44.1кГц, нормализация громкости). Лупы `engine_low/high` подключены: `engineStart` прогревает оба буфера и при готовности создаёт пару с двумя gain-узлами, а `engineSetIntensity(t)` (вызывается из drag'а по сглаженной скорости, `onDragSpeed`) кроссфейдит их. Ключи `tractor_idle/move` остаются в реестре, но не вызываются из игрового кода: нужен выбор лупа по типу перетаскиваемой фигуры (сейчас BoardView не сообщает тип в onDragSpeed) — файлы на месте и готовы, когда эта логика появится. Централизованный реестр (`src/game/sound-registry.ts`) умеет загружать сэмплы по base-aware URL и кэшировать их; `GameAudio.playSample(key, vol, fallback)` (`src/game/audio.ts`) сохраняет синтезированный fallback как защитный механизм на случай сетевого сбоя/задержки загрузки — если файл ещё не готов, звучит синтез, а как только буфер загрузится, дальнейшие вызовы используют реальный сэмпл. Каждый отсутствующий/неудавшийся файл логируется в консоль **максимум один раз за сессию** и **только в development** (`import.meta.env.DEV`); в production — без единого лишнего `console.warn`. Игра полностью играбельна даже без единого настоящего аудиофайла (fallback-синтез остаётся страховкой) — это подтверждённое, не декларативное свойство (см. `tests/sound-registry.test.ts`).

**«Подключено»** = реально вызывается из `play()` через `playSample()`, файл лежит в `public/audio/` и звучит в игре. `tractor_idle`/`tractor_move` — единственное исключение: файлы записаны и готовы, но игровой код их пока не вызывает (см. выше).

Формат: моно `.mp3` (или что легко декодируется `AudioContext.decodeAudioData`), нормализованная громкость, без щелчков на границах (важно для луп-звуков). Только собственная запись или лицензия CC0/эквивалент — никаких файлов неизвестного происхождения.

## Архитектура воспроизведения (уже реализована)
- `SampleLoader` (`sound-registry.ts`) — кэш буферов, дедупликация параллельных загрузок одного ключа, `hasFailed()` не даёт долбить сеть повторно.
- `GameAudio.playSample()` — `AudioBufferSourceNode` + `GainNode`, fade-in/fade-out (без щелчков), вариация `playbackRate` ±4%, лимит `MAX_CONCURRENT_SAMPLES=6` (не копит очередь при частых событиях).
- Пауза/реклама/скрытая вкладка — бесплатно наследуются от общего `master`-gain (сэмплы идут через тот же узел, что и синтез), отдельной остановки не требуется.
- Мотор **не перезапускается** на каждый `pointermove` (`engineStart` идемпотентен, гасится на release) — не менялось.

## Что осталось честно fallback (не подключено к реестру)
`click`, `pick`, `move`, `undo`, `thud`, `honk`, `exitRev`, `win`, `cluck`, `bark`, `meow` — чистый синтез без соответствующего ключа в реестре. Расширение — по той же схеме, что уже сделано для `star`/`gate`/`switch`/`grandpa`.
