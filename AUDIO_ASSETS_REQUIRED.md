# Требуемые аудиофайлы

Сейчас **все** звуки синтезируются WebAudio-осцилляторами (`src/game/audio.ts`) — это рабочий fallback, не финальное качество. Для продакшн-звучания желательны реальные сэмплы.

## Что уже есть (синтез, fallback)
- Мотор при перетаскивании (`engineStart`, тихий гул), «прощальный рёв» на выезде (`exitRev`).
- Голос деда `grandpa` (короткое бормотание), куры `cluck`, собака `bark`, кот `meow`.
- Удар `thud`, ворота `gate`, кнопка `switch`, звезда `star`, победа `win`, гудок `honk`, клик/отмена.

## Что желательно записать/приобрести
Формат: короткие `.webm`/`.mp3` (или decode в AudioBuffer), моно, нормализованные, без лицензионных ограничений (собственная запись или CC0).

| Ключ | Назначение | Примечание |
|--|--|--|
| `engine_idle` | холостой ход | луп, тихий |
| `engine_low` / `engine_high` | разгон | crossfade по скорости |
| `tractor_idle` / `tractor_move` | трактор | тяжелее, с «кашлем» на старте |
| `gate_creak` | скрип ворот | |
| `wood_hit` / `metal_hit` / `crate_slide` | упор/скольжение | по типу препятствия |
| `chickens_scatter` | стая кур | на резкий ход |
| `dog_bark` | собака | |
| `grandpa_reaction` | реплика деда | 2–3 варианта, разное настроение |
| `victory_drive` | выезд-победа | |

## Архитектура воспроизведения (при переходе на сэмплы)
- `AudioBufferSourceNode` + `GainNode`, плавные crossfade.
- Небольшая вариация `playbackRate` (±5–8%), чтобы не «из калькулятора».
- Ограничение одновременных источников; корректная остановка при рекламе/паузе/скрытии.
- Мотор **не перезапускать** на каждый `pointermove` (уже соблюдается: `engineStart` идемпотентен, гасится на release).
- Не добавлять чужие защищённые аудиофайлы.
