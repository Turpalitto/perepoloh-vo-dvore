# Живой двор — дизайн

## Философия
«Переполох во дворе» — не парковочная головоломка с деревенским скином, а **комедийная игра про живой сельский двор**, внутри которой качественная головоломка. Двор реагирует на игрока, а дед — главный персонаж и комментатор. Реакции декоративны: на правила хода и решатель они не влияют (кроме сюжетных фаз боссов, которые сами по себе — обычные проходимые уровни).

## События двора (`src/game/yard-events.ts`)
Core отдаёт факты хода (`MoveResult`), UI классифицирует их в `YardEvent`:
`move-start`, `move-end`, `collision`, `star-collected`, `gate-unlocked`, `tractor-move`, `level-restarted`, `level-won`.
Визуальные реакции (пыль, куры, скрип ворот, искры звезды, качание ворот) уже реализованы в `BoardView`. Слой «живого двора» добавляет **персонажа деда** и субтитры.

## Правила частоты
- Глобальный кулдаун деда `GRANDPA_GLOBAL_COOLDOWN_MS = 6000` — обычные реплики не чаще раза в ~6 c: дед не болтает каждый ход.
- Персональный `cooldownMs` у реплики — одна и та же фраза не спамится.
- Анти-повтор: реплика не повторяется сразу за собой (`lastId`).
- Сюжетные реплики (`priority > 0`: главы, боссы, финал) обходят глобальный кулдаун.
- Заметные реакции окружения ограничены `RateLimiter`.
- Реакции замолкают при паузе, рекламе, скрытой вкладке.
- `prefers-reduced-motion` убирает анимации (пузырь без «прыжка», портрет без покачивания), текст остаётся.

## Персонаж: дед (`src/game/grandpa.ts`, `src/ui/yard-reactions.ts`)
SVG-портрет с настроениями: `neutral`, `happy`, `surprised`, `grumpy`, `thinking`, `celebrating`, `pointing`. Пузырь реплики — авто-скрывающийся, `role="status" aria-live="polite"` (озвучивается скринридером; служит субтитром при выключенном звуке).

### Система реплик
Data-driven: `GrandpaLine { id, event, mood, weight?, cooldownMs?, minLevel?, maxLevel?, once?, priority? }`, текст — в ключах `grandpa.<id>` (ru/en/tr). Выбор — чистая функция `pickLine` (детерминируема через инъекцию rng). Однократные/сюжетные реплики персистятся в `SaveData.grandpaSeen`.

События реплик: `level-start`, `first-move`, `collision`, `blocked`, `tractor`, `star`, `gate`, `hint`, `win`, `win-perfect`, `many-moves`, `restart-repeat`, `chapter-start`, `boss-intro`, `boss-phase`, `boss-win`, `campaign-done`, `return`.

## Пять боссов (`src/game/boss.ts`)
Босс — **последовательность обычных, по отдельности решаемых под-уровней** (фаз). Никаких изменений core/solver: проходимость каждой фазы доказывается штатным `solve()` (тест `boss.test.ts`). Состояние = индекс фазы (сериализуемо), restart → фаза 0, undo — внутри фазы средствами уровня.

| Слот | Название | Фаз | Идея |
|--|--|--|--|
| 10 | Тракторный переполох | 2 | освободить трактор → завести |
| 25 | Куры у ворот | 2 | увести кур к кормушке → ворота+звезда |
| 50 | Соседский грузовик | 2 | выпутать грузовик → на парковку |
| 75 | Буря во дворе | 2 | разобрать ящики → кнопки/ворота |
| 100 | Великий переполох | 3 | трактор → грузовик → звезда+главные ворота |

**Статус: все 5 боссов подключены и играбельны.** Интро деда, HUD «Фаза N из M», переходы фаз без перезагрузки, уникальная победная сцена; финал (босс 100) открывает Высшую лигу той же логикой, что обычный уровень 100. Generic-оркестрация в `app.ts` (без ветвлений `id===N`), прогресс/награды только после последней фазы, undo не пересекает границу фаз, restart перезапускает текущую фазу. Полное описание — `BOSS_SYSTEM.md`. Покрыто unit (boss.test) + e2e (все 5 боссов, desktop+mobile+TV).

## Требования к аудио (см. `AUDIO_ASSETS_REQUIRED.md`)
Сейчас все звуки синтезируются WebAudio (в т.ч. голос деда `grandpa`, мотор, `exitRev`). Для продакшн-качества желательны реальные сэмплы (engine_idle/low/high, tractor, gate_creak, wood/metal hit, chickens_scatter, dog_bark, grandpa_reaction, victory_drive) — многослойно, с crossfade и вариацией playbackRate. Пока синтез — рабочий fallback.

## Производительность
- Реакции — `transform`/`opacity`, без новых DOM-узлов на `pointermove`.
- Пузырь деда — один переиспользуемый элемент.
- `RateLimiter` держит стаи кур/пыль редкими.
- Директор уничтожается при смене экрана (`disposeActiveBoard`) — нет утечек слушателей/таймеров.

## Дальнейшие идеи
- UI-интеграция боссов (интро/фазы/победа).
- Реальные аудио-сэмплы вместо синтеза.
- Больше ambient-актёров (собака, бельё) как реагирующие элементы.
- Расширение набора реплик и настроений под сезоны.

Первый босс (слот 10, «Тракторный переполох») доведён до конца по чек-листу: вступление деда → фаза 1 → промежуточная победа → переход в фазу 2 без перезагрузки → уникальная победная сцена. HUD «Фаза N из M», restart перезапускает текущую фазу (ранние фазы не теряются), undo не пересекает границу фаз, прогресс кампании и `bossDone` пишутся ТОЛЬКО после полной победы. Босс 100 открывает Высшую лигу через `completeCampaignFinale` (та же логика, что обычный уровень 100), при повторе награды не выдаются заново. Покрыто e2e (полный проход/restart/TV на desktop+mobile для всех 5 боссов); e2e-хук завершения фазы гейтится `MODE==='e2e'` и отсутствует в production (подтверждено `verify:dist`).
