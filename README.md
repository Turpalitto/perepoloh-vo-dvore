# Переполох во дворе

Парковочная головоломка для Яндекс Игр: выведи синий «жигулёнок» деда через ворота заставленного сельского двора. 36 уровней, звёзды, двор, который хорошеет с прогрессом, локализация ru/en/tr, лидерборд.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173 (mock-режим, без Яндекс SDK)
```

Полезные параметры URL: `?mock=1` — принудительный mock-режим (без попытки загрузки SDK); `?lang=ru|en|tr` — принудительный язык (по умолчанию берётся у платформы). Лидерборд: в консоли Яндекс Игр создайте таблицу с именем `yardstars` (сумма звёзд, больше — лучше).

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | дев-сервер Vite |
| `npm run typecheck` | строгая проверка типов |
| `npm test` | unit-тесты (логика, решатель, валидатор, все 36 уровней) |
| `npm run solve` | отчёт решателя: оптимум каждого уровня, сверка с `par` |
| `npm run build` | production-сборка в `dist/` |
| `npm run e2e` | браузерные тесты Playwright (нужен `npm run build`; при первом запуске `npx playwright install chromium`) |
| `npx tsx scripts/generate.ts [seed] [iter]` | поиск новых сложных уровней перебором |

## Архив для Яндекс Игр

```bash
npm run build
cd dist && tar -a -c -f ../game.zip *   # или заархивируйте содержимое dist/ любым способом
```

Требования платформы соблюдены: `index.html` в корне архива, относительные пути (`base: './'`), SDK подключается в рантайме (`/sdk.js` с fallback на CDN), игра полностью работает и без SDK.

## Промо-материалы для каталога

`npx tsx scripts/promo.ts` — генерирует `promo/icon-512.png`, `promo/cover-800x470.png`, `promo/cover-1080x608.png` из фирменного SVG (это не скриншоты игры — требование каталога). Скриншоты геймплея для карточки игры лежат в `screenshots/`.

`npx tsx scripts/promo-ai.ts` — обрабатывает сгенерированные ИИ исходники (`promo/ai-icon-src.png`, `promo/ai-cover-src.png`): срезает скруглённые углы иконки, нарезает обложку в форматы каталога и накладывает вывеску с названием. Итоговые файлы для загрузки: `ai-icon-512.png`, `ai-cover-800x470.png`, `ai-cover-titled-1080x608.png`.

## Добавление уровня

Уровни лежат в `src/levels/levels.json` — код менять не нужно. После добавления запустите `npm run solve`: он покажет оптимум (`par`) и проверит валидность/проходимость; тест `tests/levels.test.ts` не даст закоммитить уровень с неверным `par` или недостижимой звездой.

## Структура

- `src/core/` — чистая игровая логика: правила движения, BFS-решатель, валидатор
- `src/levels/levels.json` — данные 36 уровней
- `src/platform/` — интерфейс `Platform`: mock (localStorage, фейковая реклама) и Яндекс SDK
- `src/ui/` — SVG-поле с drag-управлением, экраны, двор-меню
- `src/game/` — звёзды/прогрессия двора, сохранения, WebAudio-звук
- Проектная документация: `PRODUCT_SPEC.md`, `GAME_DESIGN.md`, `TECHNICAL_DESIGN.md`, `IMPLEMENTATION_PLAN.md`
