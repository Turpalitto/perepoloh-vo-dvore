# Переполох во дворе

Парковочная головоломка для Яндекс Игр: выведи «жигулёнок» деда через ворота заставленного сельского двора. 100 уровней в девяти главах, авторская механика «Живой двор» с нажимными кнопками и замками, боссы, ежедневный уровень, недельные кубки, ежедневный подарок, 12 достижений, 300 звёзд, развивающийся двор, скины, локализация ru/en/tr, два лидерборда и полное управление Android TV-пультом.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173 (mock-режим, без Яндекс SDK)
```

Полезные параметры URL: `?mock=1` — принудительный mock-режим только в dev/e2e-сборках; `?tv=1` — эмуляция TV-устройства только вместе с mock для QA; `?lang=ru|en|tr` — QA-переопределение языка (на первом запуске язык берётся у платформы); `?daytime=day` — фиксированная дневная палитра для скриншотов. В production mock-код и имитация рекламы не попадают. В консоли Яндекс Игр создайте таблицы `yardstars` (сумма звёзд) и `dailystreak` (серия дней), обе — «больше лучше».

Remote Config читает необязательные флаги `interstitial_every`, `interstitial_min_level`, `interstitial_min_session_ms`, `free_hints_per_session`. Без них используются безопасные значения 6 / 10 / 240000 / 1: за полную кампанию возможно не более 11 interstitial, и ни одного в первые четыре минуты сессии.

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | дев-сервер Vite |
| `npm run typecheck` | строгая проверка типов |
| `npm test` | unit-тесты (логика, SDK, сохранения, daily и все 100 уровней) |
| `npm run solve` | отчёт решателя: оптимум каждого уровня, сверка с `par` |
| `npm run rebalance` | детерминированно применяет проверенный ребаланс кампании и пересчитывает `par/par2` решателем |
| `npm run build` | production-сборка в `dist/` |
| `npm run e2e` | собирает специальную e2e-версию с mock SDK и запускает браузерные тесты Playwright |
| `npm run screenshots:yandex` | снимает два desktop- и два mobile-геймплейных кадра; нужен запущенный preview |
| `npm run generate -- [seed] [iter]` | поиск новых сложных уровней перебором |

Адаптивный e2e-прогон проверяет меню и активный уровень на десяти размерах от 320×568 до 1920×1080, портретную и альбомную ориентации, поворот экрана без перезагрузки, touch- и mouse-управление, отсутствие системной прокрутки и минимальную touch-зону 44×44 px. TV-сценарии отдельно проходят меню и первый уровень только событиями `Arrow*`, `Enter`, `HISTORY_BACK` и `EXIT`.

## Архив для Яндекс Игр

```bash
npm run build
cd dist && tar -a -c -f ../game.zip *   # или заархивируйте содержимое dist/ любым способом
```

Production использует только официальный относительный `/sdk.js`; абсолютных S3/CDN URL и mock-рекламы в архиве нет. `index.html` лежит в корне архива, игровые ассеты используют относительные пути (`base: './'`), а legacy-бандл обеспечивает запуск в заявленных Яндексом старых браузерах. Локальная разработка без SDK работает только в dev/e2e-режимах.

## Промо-материалы для каталога

`npm run promo:puzzle` — повторно нарезает финальные материалы из `ai-cover-puzzle-v2-src.png`: обложку `ai-cover-puzzle-v2-800x470.png` и иконку `ai-icon-puzzle-v2-512.png`. Устаревшие варианты удалены, чтобы в Консоль нельзя было случайно загрузить неверный файл.

`npm run screenshots:yandex` — переснимает реальные экраны в форматах 720×1280 и 1280×720. `npm run verify:dist` дополнительно проверяет размеры и 24-разрядный RGB-формат шести файлов, выбранных для публикации.

## Добавление уровня

Уровни лежат в `src/levels/levels.json` — код менять не нужно. После добавления запустите `npm run solve`: он покажет оптимум (`par`) и проверит валидность/проходимость. Тесты дополнительно требуют, чтобы после обучения в оптимальном маршруте участвовала минимум половина препятствий. Категории означают реальную сложность: easy ≤ 5 ходов, medium 6–10, hard ≥ 11.

## Структура

- `src/core/` — чистая игровая логика: правила движения, BFS-решатель, валидатор
- `src/levels/levels.json` — данные 100 уровней
- `src/platform/` — интерфейс `Platform`: mock (localStorage, фейковая реклама) и Яндекс SDK
- `src/ui/` — SVG-поле с drag-управлением, экраны, двор-меню
- `src/game/` — звёзды/прогрессия двора, daily Worker, сохранения, WebAudio-звук
- Проектная документация: `PRODUCT_SPEC.md`, `GAME_DESIGN.md`, `TECHNICAL_DESIGN.md`, `IMPLEMENTATION_PLAN.md`
