# Что пропущено / не сделано (эта сессия)

Этот файл фиксирует задуманные, но **осознанно отложенные** улучшения (проверка: `npm run typecheck && npm run lint && npm test && npm run build && npm run verify:docs`, всё зелёное — итоги в `CHANGELOG.md`).

## 1. «Бесконечный двор» — дневные модификаторы (day-modifiers)
Не реализовано: вариация заездов Endless по дням (например, сдвиг состава фигур, лёд/куры/доски в зависимости от дня недели).

**Причина:** требуется изменение `src/core/levelgen.ts`/`src/core/game.ts` — это core-механики. По правилам проекта (`AGENTS.md`, «Не менять core-правила без прямого разрешения») трогать их нельзя без отдельного разрешения. Вдобавок вариация генерации заездов обязана сохранять **доказуемую проходимость**, что сильно усложняет ремикс влиянием на solver.

## 2. Реальные аудио-сэмплы (голос деда, скрип ворот)
Не реализовано: записанные сэмплы `grandpa_mumble_1-3.mp3` (P0) и `gate_swing.mp3` (P3) из `AUDIO_ASSETS_REQUIRED.md`.

**Причина:** требуют настоящих аудио-файлов (собственная запись или CC0). Синтез WebAudio остаётся рабочим fallback; файлы добавить невозможно без записи/лицензионного источника.

## 3. Рефакторинг `src/ui/app.ts` (god object)
Не реализовано: вынос экранов/контроллера из ~2900-строчного `src/ui/app.ts` в отдельные модули.

**Причина:** рефакторинг перед релизом рискован (высокий шанс регрессий на стыке `runLevel`/`finishLevel`/боссов). Отложено в P3 (документировано в `TECHNICAL_DESIGN.md`).

## 4. Облачное сохранение (cloud-save) через платформу
Не реализовано: сохранеем на сервер Яндекса для переселения прогресса между устройствами.

**Причина:** требует расширения контракта `Platform` (вне `src/platform/` нельзя), а сейв-формат нельзя менять без миграции. Существующий union-merge `SaveStore` уже готов к такой интеграции, но сам вызов платформы — отдельная задача.
